# Require A Clean Checkout For Publish

Status: Active. The user approved this change and plan. The branch starts at
`origin/main`. PR #135 is not part of this change. Completion requires the pull
request to merge.

## Contract And Decisions

`mokly publish` checks HEAD and repository status before export and again before
Plan. It rejects changes anywhere in the repository before a receiver request.
It ignores Git-ignored files, this run's output directory, and Mokly-owned cache
and temporary paths. Generated files that Git tracks always count.

The current configuration no longer accepts `generatedOutput`. Git tracking
selects committed output or derived output, as it does for `mokly check`.
Publish compares compiled generated bytes with committed output without writing
the generated tree. Derived output must be ignored by Git. The upload manifest
and receiver contract stay unchanged. There is no override flag.

The errors are `git-uncommitted` and `build-stale`. Each error shows its headline,
at most 20 paths and a remaining-path count, and its recovery hint in plain and
rich output. Changes found after export identify that phase.

Evidence stays under `.context/publish-clean-checkout/`.
