# Member roles

Every person in a workspace has one role. The role sets what the person can
change.

| Role   | What the person can do                                     |
| ------ | ---------------------------------------------------------- |
| Owner  | Everything an admin can do, and delete the workspace       |
| Admin  | Invite and remove people, change roles, and manage billing |
| Member | Open, edit, and share projects                             |

## Choose a role

Give a new person the Member role, unless they help to run the workspace.
Owners and admins can change a role at any time.
