# Sidecar Security

The sidecar runs consumer code with the consumer build's trust.
It inherits its environment except the names that the [source worker environment](./mokly-sidecar-modules.md#source-root-workers) omits, so sidecar code does not receive the publish token.
The [token exposure rule](./mokly-upload.md#token-exposure) states the limit of this protection.
Each PostCSS child puts selected dependency directories before inherited `NODE_PATH` entries. Base dependency installation
disables lifecycle scripts by default and has a time limit. An explicit working-tree opt-in can run them inside the owned process tree.
