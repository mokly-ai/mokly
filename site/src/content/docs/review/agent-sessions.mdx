## A live session on a branch

A branch session runs Mokly serve in a sandbox, so the screens you are looking
at are the ones that branch renders right now.

## The agent beside the screen

An agent sits beside the viewer and edits the mockup source of the branch the
session is on. You read the screen and ask for the change in the same place.

## Publish back to the branch

When the screens are right, publish from the session and the work goes back to
the branch it came from.
