## Generate the catalogue

```shell
npx mokly build
```

Build validates your entries, renders every screen and writes the result
under `mockupsDir`: one document per viewport and color scheme, plus
`mokly-manifest.json`. Writes are transactional, so a failed build leaves the
previous output in place.

## Commit the output, or derive it

By default generated files are committed beside their source. `mokly check`
then proves the committed bytes match the current compilation, and a
comparison reads its baseline straight from Git.

If you would rather keep generated files out of Git, set
`generatedOutput: "derived"` and add ignore rules for the generated routes,
the manifest and `.mokly-cache/`. Check then requires those files to be
untracked instead.

## Validate without writing

```shell
npx mokly check
```

Check calculates the same bytes without writing them. In the default mode it
reports files that are missing, stale or no longer part of the catalogue.
