# Catalogue move pairing

`pair.ts` owns the pure ordered policy. Callers supply validated entries and
injectable content signals. `pass.ts` evaluates complete candidate sets before
accepting unique mutual matches. Ambiguity survives later iterations and passes.
Identical-content passes repeat until no new pair appears. `fingerprints.ts`
groups normalised hashes before full equality checks. Only differing ignore
contracts need pairwise fallback; `review/ignore.ts` owns both normalisation paths.

`read.ts` loads candidate documents through the confined asset reader.
`content.ts` compares complete rendered view sets, flow steps and component
structure. `markdown_sources.ts` reads private body evidence from the pinned Git
commit and accepted compilation. Derived baseline output and source reads use
separate capabilities. `visible_text.ts` extracts deterministic page body lines;
`similarity.ts` implements the line-multiset score. Shared HTML templates never
contribute to document similarity.

`links.ts` and `resource_links.ts` canonicalise comparison material only. Real
URLs remain available to resource traversal, CSS matching and snapshot capture.
`resources.ts` retains generated byte evidence. `resource_routes.ts` derives
unique stylesheet, asset and document-resource aliases from accepted entry
moves and corresponding generated references in paired views. Surviving
consumers retain their own resource routes. `source_moves.ts` maps inventoried
owned sources and suppresses dependency paths only after a confined byte proof.
`source_files.ts` shares private current/historical reads with Markdown evidence.
Equal mapped bytes suppress current generated dependency/shared-impact
reasons; changed resources retain normal attribution. The shared CSS tokenizer
in `src/css_references.ts` resolves URL tokens without rewriting other CSS.
`identity.ts` maps catalogue references without confusing a reused path's kind.

Serve reports diagnostics only after accepting a classification generation.
Export reports them through its diagnostic callback before publication removes
artifact summaries. These diagnostics do not become catalogue metadata.
